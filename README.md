# Modern Calculator 🧮

A modern and responsive calculator built using HTML, CSS, and JavaScript. It features a sleek glassmorphism UI, dark theme, neon purple accents, smooth button animations, and a clean user-friendly design.

## ✨ Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division
- Modern glassmorphism design
- Dark theme with neon gradient accents
- Smooth hover and click animations
- Responsive layout for mobile and desktop
- Clear button to reset the display
- Error handling for invalid expressions

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start calculating!

## 📁 Project Structure
- `index.html` — Calculator structure
- `sss.js` — Calculator functionality
- `style.css` — Modern calculator styling (if CSS is stored separately)

## 🎯 Purpose
This project was created to practice frontend web development and improve HTML, CSS, and JavaScript skills.
